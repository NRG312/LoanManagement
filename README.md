# Loan Management App

A desktop application built with C# and Windows Forms to organize loans and manage installment payment information.

## About the Project

The application was created to make it easier to keep track of loans, organize them into categories, and access installment payment information in one place.

The project focuses on practical desktop application development, UI design, data management, and JSON-based persistence.

## Features

- Create and manage loans
- Organize loans into categories
- Display loans in a graphical user interface
- Add and remove installments
- Store and load application data using JSON files
- Manage loan information through interactive controls

## Technologies

- C#
- .NET
- Windows Forms
- System.Text.Json
- Object-oriented programming (OOP)

## Project Structure

The application separates its main responsibilities into dedicated classes, including:

- `Loan` — represents loan data
- `LoanManager` — manages loan-related operations
- `LoanControl` — displays loan information in the UI
- `SaveData` — handles saving and loading data
- `NewLoanForm` — provides a form for creating loans

## What I Learned

- Building desktop applications with Windows Forms
- Handling UI events and user interactions
- Working with classes, collections, and object-oriented design
- Serializing and deserializing objects using JSON
- Separating application logic from UI components

# Aplikacja do zarządzania pożyczkami

Aplikacja desktopowa stworzona w języku C# przy użyciu technologii Windows Forms, służąca do ewidencjonowania pożyczek oraz zarządzania informacjami o spłatach ratalnych.

## O projekcie

Aplikacja powstała w celu ułatwienia monitorowania pożyczek, ich kategoryzowania oraz zapewnienia dostępu do szczegółów dotyczących rat w jednym miejscu.

Projekt koncentruje się na praktycznych aspektach tworzenia aplikacji desktopowych, projektowaniu interfejsu użytkownika (UI), zarządzaniu danymi oraz ich trwałym zapisywaniu w formacie JSON.

## Funkcjonalności

- Tworzenie pożyczek i zarządzanie nimi
- Kategoryzowanie pożyczek
- Prezentacja pożyczek w graficznym interfejsie użytkownika
- Dodawanie i usuwanie rat
- Zapisywanie oraz wczytywanie danych aplikacji za pomocą plików JSON
- Zarządzanie informacjami o pożyczkach poprzez interaktywne elementy sterujące

## Technologie

- C#
- .NET
- Windows Forms
- System.Text.Json
- Programowanie obiektowe (OOP)

## Struktura projektu

Aplikacja dzieli swoje główne zadania pomiędzy dedykowane klasy, w tym:

- `Loan` — reprezentuje dane pożyczki
- `LoanManager` — zarządza operacjami związanymi z pożyczkami
- `LoanControl` — odpowiada za wyświetlanie informacji o pożyczce w interfejsie użytkownika
- `SaveData` — obsługuje zapisywanie i wczytywanie danych
- `NewLoanForm` — udostępnia formularz służący do tworzenia nowych pożyczek

## Czego się nauczyłem

- Tworzenia aplikacji desktopowych przy użyciu Windows Forms
- Obsługi zdarzeń w interfejsie użytkownika oraz interakcji z użytkownikiem
- Pracy z klasami, kolekcjami i zasadami projektowania obiektowego
- Serializacji i deserializacji obiektów z wykorzystaniem formatu JSON
- Rozdzielania logiki aplikacji od komponentów interfejsu użytkownika
